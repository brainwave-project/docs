# Experiment 3 — Arabic normalization and retrieval

Start with [the step-by-step guide](EXPERIMENT-3-GUIDE.md), then fill [the protocol](PROTOCOL.md) before measured runs. The guide covers the new Evaluation → Arabic Norm page, the included diagnostic data, a bounded MIRACL pilot, and the full-corpus CLI workflow.

[The article draft](ARTICLE-DRAFT.md) is unpublished and contains explicit results placeholders. [Sources and dataset alternatives](SOURCES.md) document the official upstream data and model.

No MIRACL or dense-retrieval findings are asserted by these files. The included 16-passage, 12-query Arabic fixture tests experimental mechanics and illustrates collisions; it is not a representative benchmark.
