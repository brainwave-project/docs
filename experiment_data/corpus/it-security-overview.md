# IT Security Awareness Overview

## Phishing
Employees should report suspicious emails using the "Report Phishing" button
rather than clicking links or downloading attachments from unknown senders.

## Device Security
Company devices must have disk encryption and screen-lock enabled at all
times. Devices should never be left unattended in public places.

## Reporting Incidents
Suspected security incidents must be reported to the security team within
one hour of discovery via the incident hotline.
