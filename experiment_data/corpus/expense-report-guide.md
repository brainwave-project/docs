# How to File an Expense Report

## Step-by-Step
1. Open the Expense app and select "New Report".
2. Photograph or scan each receipt and attach it to the corresponding line
   item.
3. Select the correct expense category from the dropdown.
4. Add a brief business justification for entertainment or travel expenses.
5. Submit for approval.

## Common Mistakes
The most common reason for rejected reports is a missing receipt image or an
expense category that does not match the receipt description.
