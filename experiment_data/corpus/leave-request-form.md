# Leave Request Form — Instructions

## How to Submit
1. Log in to the HR portal and navigate to "Time Off".
2. Select the leave type and the start and end dates.
3. Attach supporting documentation if required (e.g., medical certificate).
4. Submit the request for manager review.

## Editing a Request
Pending requests can be edited or withdrawn before manager approval. Once
approved, changes require a new request plus cancellation of the original.

## Notifications
Employees receive an email notification when a request is approved,
rejected, or requires additional information.
